# Changan UNI-V for Home Assistant

面向长安引力域 3.1.0 的 Home Assistant 自定义集成，当前版本只提供车辆云端状态读取。

这是社区逆向兼容项目，与长安汽车无官方关联。

## 当前能力

- 剩余油量、续航、总里程、温度、电瓶电压、四轮胎压、发动机及空调状态
- 账户失效后触发 Home Assistant 重新认证流程
- 自动使用 refresh token 刷新访问令牌（账户会话含 refresh token 时）
- 车辆标识只以不可逆摘要用于实体唯一标识
- 不保存密码、短信验证码、PIN 或精确位置，不记录 token

## 安全边界

远程空调等车辆控制保持禁用。控制接口仅在一次用户明确批准的室外实车验证完成后才会加入。

当前 0.3.0 是服务器部署基线。图片验证码和短信验证码登录将在完成引力域登录协议定向验证后加入；此时可先创建集成，`账户需要认证` 实体会保持开启。

## 安装

1. 在 HACS 中添加本仓库为“集成”类型的自定义仓库。
2. 下载 `Changan UNI-V` 并重启 Home Assistant。
3. 在“设置 → 设备与服务 → 添加集成”中搜索 `Changan UNI-V`。

支持 Home Assistant 2026.5 及以上版本。
